# Магистральная энергосеть Украины — карта

Интерактивная карта магистральной энергосети Украины: **750 / 500 / 330 кВ**,
межгосударственные линии и пункты импорта/экспорта.

Сайт: https://okinokii.github.io/750Kv/

## Страницы

- `index.html` — интерактивная карта на Leaflet (подложки OpenStreetMap и Esri, без API-ключей).
- `karta-750-500-330.html` — автономная SVG-карта, работает вообще без внешних сервисов.
- `ukraine_750kv_substations.csv` — 36 узлов (подстанции, ОРУ АЭС, пограничные пункты).
- `ukraine_lines.csv` — 36 линий (внутри страны и межгосударственные).

## Легенда

-красные — ПС и ЛЭП 750 кВ; фиолетовые — 500 кВ; бирюзовые — 330 кВ;
зелёные — действующие межгосударственные направления;
оранжевый пунктир — проект/стройка; серый пунктир — выведенные и исторические объекты.

## Источники и точность

Данные собраны из открытых источников: uk/en.wikipedia.org, НЕК «Укренерго»,
zakon.rada.gov.ua, OpenStreetMap/Nominatim, тендерная и проектная документация.
Там, где точные координаты отсутствуют, маркер поставлен по населённому пункту —
погрешность указана в карточке объекта.

Объекты в зоне боевых действий / оккупации (Донбасская, Южнодонбасская, Каховская,
Запорожская АЭС, Мелитопольская и др.) отмечены как требующие уточнения статуса.
